# Artwork provenance

The assets were created with the built-in OpenAI image-generation tool for this project. They are original generated artwork. No external API key was used. Original outputs remain in the Codex generated-images folder.

## Assets

- `public/assets/island-hero.png` — 1672 × 941 landscape, painterly coastal island. Dark teal water gives text space on the left.
- `public/assets/terrain-atlas.png` — 1536 × 1024, six square 512 × 512 cells; rows are **wood, wheat, wool / brick, ore, desert**. No gutters. Intended for hex clipping and resource-card artwork.
- `public/assets/pieces-atlas.png` — transparent PNG, three equally spaced columns: **settlement, city, robber**. Use alpha and crop each third without distorting aspect ratio. Player-colored bases or outlines may distinguish ownership.
- `public/assets/lobby-slate.webp` — 640 × 640 textured dark slate, downscaled and compressed from the original image. Tiled beneath the multiplayer screen and panel headers.
- `public/assets/development-atlas.webp` — 1152 × 768 painted card art in a 3 × 2 grid: **Knight, Victory point, Road building / Invention, Monopoly, decorative cloth**. Used for the development hand and card inspector.
- `public/assets/terrain-{wood,wheat,wool,brick,ore}-variants.webp` — five 1024 × 1024 atlases, each with four alternatives in a 2 × 2 grid. The original cell is the fifth tile in each resource family.
- `public/assets/ocean-surface.webp` — 1536 × 1024 painted water for the match backdrop.
- `public/assets/port-sloop.webp` — transparent painted merchant sloop sprite used beside the board's piers.
